## Dependencies

Before getting started, you will need:

- PHP (8+)
- Symfony

## Usage

`composer install`

`symfony serve`

`bin/console tailwind:build -w`

`bin/console doctrine:migrations:migrate`

`bin/console populate:db:from:contentful`

`bin/console importmap:install`

`/change-locale/en`
`/change-locale/nl`

`bin/console tailwind:build -w`
